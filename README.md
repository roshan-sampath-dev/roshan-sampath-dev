## 🔍 What Does a Data Analyst Actually Do?

Since not everyone works with data day-to-day, here's the short version of what I do:

| Stage | What Happens |
|---|---|
| **1. Collect** | Pull raw data from spreadsheets, databases, or business systems |
| **2. Clean** | Fix missing values, duplicates, and inconsistent formatting so the data can be trusted |
| **3. Analyze** | Use SQL, Excel, and Python to find trends, patterns, and outliers |
| **4. Visualize** | Build dashboards in Power BI / Tableau that make insights easy to understand at a glance |
| **5. Communicate** | Translate the numbers into a clear story that helps managers make better decisions |

In short: **I turn "we have a lot of data" into "here's what to do about it."**
